# 专题 3：具身主动重定位

## 研究问题

比赛要求机器人在剧烈运动、跨域切换或感知退化后主动找回定位。现有机器人已有 `scan_map_relocalization_node.py`、`amcl_swing_relocalization_node.py` 和 AMCL/Nav2，但仍依赖外部粗位姿或手动初始位姿，没有自动成功判定和成功率统计。

## 主要路线

| 路线 | 机制 | 适配判断 |
|---|---|---|
| AMCL 全局重定位 | 粒子在全局地图上重采样，利用激光观测收敛 | 现有 Nav2 生态可复用；需要定义触发、收敛和安全重置 |
| Scan-to-Map | 用当前扫描和地图匹配生成候选位姿 | 现有已有局部实现；应补候选生成、置信度和自动闭环 |
| Place recognition | Scan Context 等全局描述子先找位置，再几何精配准 | 适合 3D 点云或较丰富结构；2D A2 需要单独验证感知别名风险 |
| 主动信息增益动作 | 选择转向/移动动作，减少位姿分布熵或候选多峰 | 理论完整但动作模型、仿真和安全验证成本较高 |
| 分层恢复 | 低成本旋转优先，失败后扩大搜索/移动，最后人工接管 | 最符合比赛周期和现有节点基础 |

## 可靠来源

### A1 — ReinitializeGlobalLocalization

- 来源：Nav2 官方行为树动作文档；[官方页面](https://docs.nav2.org/configuration/packages/bt-plugins/actions/ReinitializeGlobalLocalization.html)。状态：`official`、`inspected`。
- 研究问题：严重失定位或 kidnapped robot 情况下触发 AMCL 全局重定位。
- 核心机制：通过服务触发全局重定位，并提供行为树动作接口。
- 实验/结果：文档是 API 参考，没有给出成功率实验。
- 可借鉴：把“请求重定位”作为明确的系统动作边界，而不是让任意节点直接修改位姿。
- 不能证明：调用服务成功不等于重定位成功；必须增加稳定性和误差判定。

### A2 — Mapping and Localization / Nav2 Concepts

- 来源：Navigation2 官方文档；[Mapping and Localization](https://docs.nav2.org/setup_guides/sensors/mapping_localization.html)、[Navigation Concepts](https://docs.nav2.org/concepts/)。状态：`official`、`inspected`。
- 核心内容：SLAM Toolbox 和 AMCL 的职责、`/scan` 约定、`map -> odom -> base_link` TF 边界、定位与里程计的分工。
- 可借鉴：当前系统保持 TF 契约，将重定位输出限定为 `map -> odom` 或受控 `/initialpose`。
- 不能证明：官方教程只说明架构和配置，不证明当前机器人在退化场景下的成功率。

### A3 — Active Mobile Robot Localization

- 作者：Wolfram Burgard、Dieter Fox、Sebastian Thrun；年份：1997；IJCAI；[CMU 论文页](https://publications.ri.cmu.edu/active-mobile-robot-localization)。状态：`inspected`（机构摘要）。
- 研究问题：传统定位被动接收传感器，如何主动控制机器人运动和传感器方向来提高定位效率。
- 核心方法/实验：用理性准则选择运动方向和传感器指向，处理噪声传感器和近似地图，在结构化办公室移动机器人上验证。
- 可借鉴：将主动旋转/移动视为“获取信息”的动作，不要只把旋转当作机械动作。
- 不能证明：论文年代较早，动作空间和传感器与当前系统不同，不能直接给出比赛阈值。

### A4 — Integrating active localization into high-level robot control systems

- 作者：Michael Beetz、Wolfram Burgard、Dieter Fox、Armin B. Cremers；年份：1998；[Elsevier](https://www.sciencedirect.com/science/article/pii/S0921889098000098)，DOI：`10.1016/S0921-8890(98)00009-8`。状态：`abstract-only`。
- 研究问题：如何让高层任务控制监测定位置信度，并在不确定性过大时自主重定位。
- 核心方法：将定位确定性监测和自动重定位接入高层控制系统。
- 可借鉴：比赛需要的不只是匹配算法，还需要 `confidence -> trigger -> action -> verify -> recover` 的控制闭环。
- 不能证明：摘要没有给出当前比赛所需的成功率计算方法或具体动作策略。

### A5 — Motion Planning for Global Localization in Non-Gaussian Belief Spaces

- 作者：Saurav Agarwal、Amirhossein Tamjidi、Suman Chakravorty；年份：2015；[arXiv](https://arxiv.org/abs/1511.04634)。状态：`abstract-only`。
- 研究问题：全局定位时多峰、非高斯信念导致单次观测无法区分候选位置，如何规划动作使其收敛。
- 核心方法/实验：在不确定性下规划动作，序贯消除多峰假设；物理地面机器人迷宫实验。
- 可借鉴：主动重定位应记录候选数量、置信度熵或匹配分布是否变得单峰，而不只记录“最后定位成功”。
- 不能证明：完整规划器和 belief-space 计算成本可能超出当前比赛周期。

### A6 — SLAP: Simultaneous Localization and Planning Under Uncertainty

- 作者：Ali-akbar Agha-Mohammadi、Saurav Agarwal、Sung-Kyun Kim、Suman Chakravorty、Nancy M. Amato；年份：2015；[arXiv](https://arxiv.org/abs/1510.07380)。状态：`abstract-only`。
- 研究问题：定位不确定性、环境变化和 kidnapped robot 情况下同时做路径规划和主动定位。
- 核心方法/实验：在 belief space 中动态重规划，物理机器人上验证大扰动和变化环境。
- 可借鉴：主动定位动作应受可通行性和安全约束，不能为了信息量随意移动。
- 不能证明：POMDP/连续 belief-space 方案对现有 Jetson 和截止时间的实现成本很高。

### A7 — Scan Context: Egocentric Spatial Descriptor for Place Recognition within 3D Point Cloud Map

- 作者：Giseop Kim、Ayoung Kim；年份：2018；IROS；[论文](https://gisbi-kim.github.io/publications/gkim-2018-iros.pdf)、[项目页](https://gisbi-kim.github.io/publication/kim2018scan/)。状态：`inspected`（论文摘要和正文可见部分）。
- 研究问题：用 3D 结构描述位置，解决旋转变化和长期地点识别。
- 核心方法/实验：把 LiDAR 可见空间按方位/半径分桶，使用最大高度形成 Scan Context，并用两阶段搜索找回环/地点。
- 可借鉴：全局候选生成与几何精配准分层；动态物体和感知别名要进入失败样本。
- 不能证明：当前 A2 是二维 LaserScan，直接使用 3D Scan Context 需要新数据和适配。

### A8 — lidar_localization_ros2

- 作者/来源：rsasaki0109；年份：2025–2026 活跃项目；[GitHub](https://github.com/rsasaki0109/lidar_localization_ros2)、[global localization docs](https://github.com/rsasaki0109/lidar_localization_ros2/blob/main/docs/global_localization.md)。状态：`inspected`（README、global localization 和 benchmark 说明）。
- 研究问题：ROS2 中基于点云地图进行 NDT/GICP 定位、全局候选搜索和丢定位恢复。
- 核心方法：BBS 2D/候选生成、NDT/GICP 评分、候选到 `/initialpose` 的受控重置、G3 recovery supervisor 和可复现 rosbag benchmark。
- 关键结果：项目公开验证日志中有运行时、候选数、RMSE 和 Nav2 reinit 记录；这些是该项目结果，不是 DG-202611 结果。
- 可借鉴：候选生成—打分—安全门—重置—验证的完整工程链路和日志字段。
- 不能证明：其 3D LiDAR/数据集和 ROS 发行版与当前机器人一致，不能未经审计直接依赖。

## 推荐的主动重定位候选闭环

1. 触发：AMCL 协方差/粒子质量、Scan-to-Map 分数、连续匹配失败或 GNSS/LiDAR 质量门触发。
2. 动作：优先原地小角度旋转；若观测不足，再执行受安全边界限制的短距离移动；全局搜索暂作为后备。
3. 观测：每个动作阶段收集多帧 `/scan`、`/odom`、`/imu/data` 和匹配分数。
4. 判定：候选位姿与真值/参考位姿误差满足预设阈值，匹配分数/内点率达到阈值，且连续若干帧稳定；否则判失败，不发布新的全局修正。
5. 记录：触发原因、动作序列、候选数量、最佳/次佳分数、耗时、最终误差、是否恢复导航和失败原因。

这是实验协议候选，不是已经批准的成功率定义。
