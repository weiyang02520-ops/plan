# 专题 5：DG-202611 三个指标的测试方法

## 重要边界

官方方案给出三个量化目标：平面/高程定位误差优于 20 cm、动态目标剔除后的相邻帧有效特征重复率不低于 95%、主动重定位成功率高于 95%。公开比赛方案没有在当前资料中提供足够的测试细则，因此下面是**来源启发的测试候选**，不是官方最终口径，也不是已完成实验。

## M1 — A benchmark for the evaluation of RGB-D SLAM systems

- 作者：Jürgen Sturm、Nikolas Engelhard、Felix Endres、Wolfram Burgard、Daniel Cremers；年份：2012；IROS；DOI：`10.1109/IROS.2012.6385773`；[TUM 机构页](https://portal.fis.tum.de/de/publications/a-benchmark-for-the-evaluation-of-rgb-d-slam-systems/)、[论文 PDF](https://cvai.cit.tum.de/_media/spezial/bib/sturm12iros.pdf)。状态：`inspected`。
- 研究问题：如何用高精度、时间同步的真值轨迹比较 RGB-D SLAM。
- 核心方法/实验：提供数据格式、标定、真值和自动评测工具；使用 ATE 评价全局轨迹误差，使用 RPE 评价局部漂移/相对运动误差。
- 可借鉴：DG-202611 必须保存估计轨迹、真值轨迹、时间同步和评测脚本，而不是只给一张曲线图。
- 不能证明：RGB-D benchmark 的 ATE/RPE 口径不自动等于比赛 20 cm 的平面/高程口径。

## M2 — TUM RGB-D official evaluation tools

- 来源：TUM Computer Vision Group；[官方评测页面](https://cvg.cit.tum.de/data/datasets/rgbd-dataset/online_evaluation)、[工具页](https://cvg.cit.tum.de/data/datasets/rgbd-dataset/tools)。状态：`official`、`inspected`。
- 核心内容：提供 ATE、RPE 评测模式和轨迹输入/对齐工具。
- 可借鉴：评测程序、对齐方式、时间戳处理和输出 RMSE/统计摘要的组织方式。
- 不能证明：不能把对齐后的 ATE 直接作为高程误差；需要保留 ENU/地图坐标的绝对参考。

## M3 — KITTI Odometry Evaluation

- 来源：KITTI 官方 benchmark；[官方评测页面](https://www.cvlibs.net/datasets/kitti/eval_odometry.php)。状态：`official`、`inspected`。
- 核心内容：按不同子序列长度计算平移和旋转误差，平移误差用百分比、旋转误差按距离归一化。
- 可借鉴：按轨迹段长度和多次窗口报告误差，防止单个终点误差掩盖中途退化。
- 不能证明：KITTI 的车辆/3D 激光真值设置与室内移动机器人、高程 20 cm 目标不同。

## M4 — USIP repeatability definition

- 作者：Jiaxin Li、Gim Hee Lee；年份：2019；ICCV；[论文正文](https://openaccess.thecvf.com/content_ICCV_2019/html/Li_USIP_Unsupervised_Stable_Interest_Point_Detection_From_3D_Point_Clouds_ICCV_2019_paper.html)。状态：`inspected`。
- 核心定义：两帧点云有已知变换时，将第一帧关键点变换到第二帧；若其到第二帧最近关键点的欧氏距离小于 `ε`，则为 repeatable；相对重复率为 `|Q_rep| / |Q|`。
- 可借鉴：为比赛指标定义候选：先规定相邻帧、重叠区域、运动补偿变换、距离阈值 `ε`、有效特征集合和分母。
- 不能证明：比赛“有效特征”可能不是 USIP 关键点；不能未经主办方确认直接采用其阈值和分母。

## M5 — 3DMatch benchmark

- 作者：Andy Zeng 等；年份：2017；[项目主页](https://3dmatch.cs.princeton.edu/)、[论文](https://arxiv.org/abs/1603.08182)。状态：`inspected`。
- 核心内容：将局部 3D 对应关系分成匹配/非匹配，分别评价描述子和几何注册；项目页提供数据和评测脚本。
- 可借鉴：把“检测到同一特征”“描述子匹配正确”“最终几何注册正确”拆成三项，不混成一个 95% 数字。
- 不能证明：3DMatch 的 precision/recall 不是比赛的相邻帧特征重复率。

## M6 — Evaluation of Interest Point Detectors

- 作者：Cordelia Schmid、Roger Mohr、Christian Bauckhage；年份：2000；IJCV 37(2):151–172；DOI：`10.1023/A:1008199403446`；[DOI](https://doi.org/10.1023/A:1008199403446)。状态：`metadata/abstract-only`。
- 研究问题：如何定量比较兴趣点检测器的重复性和信息质量。
- 核心内容：将重复性作为跨视角/扰动后能否检测相同位置的重要指标，并考虑检测不确定性。
- 可借鉴：实验应固定扰动类型、空间容差、可见/重叠区域和统计方式。
- 不能证明：该工作主要是通用兴趣点检测器评价，不直接给出 DG-202611 的 95% 口径。

## M7 — SLAMBench: Introducing SLAMBench

- 作者：Matthias Schmalz 等；年份：2014；[arXiv](https://arxiv.org/abs/1410.2167)。状态：`abstract-only`。
- 研究问题：如何统一比较 SLAM 的准确性、性能和能耗。
- 核心内容：提供可复现软件框架、数据/真值、精度和运行时/能耗分析。
- 可借鉴：比赛性能分析除了误差，还应记录 Jetson CPU/GPU/内存、处理频率、丢帧、延迟和功耗边界。
- 不能证明：SLAMBench 的数据和实现不代表当前机器人实机性能。

## M8 — The TUM VI Benchmark for Evaluating Visual-Inertial Odometry

- 作者：David Schubert、Thore Goll、Nikolaus Demmel、Vladyslav Usenko、Jörg Stückler、Daniel Cremers；年份：2018；[arXiv](https://arxiv.org/abs/1804.06120)。状态：`abstract-only`。
- 研究问题：如何为视觉惯性里程计提供多样场景、高频真值和时间同步评测。
- 核心内容：强调传感器与真值对齐、数据集场景变化和轨迹评估。
- 可借鉴：实验记录要有传感器时间戳、外参、真值同步和运动场景标签。
- 不能证明：视觉惯性 benchmark 不能直接替代 LiDAR/BDS 现场实验。

## M9 — A Dynamic Points Removal Benchmark in Point Cloud Maps

- 作者：论文作者团队；年份：2023；[arXiv](https://arxiv.org/abs/2307.07260)。状态：`abstract-only`。
- 研究问题：为动态点剔除方法提供可比较的公开 benchmark。
- 可借鉴：动态点处理应报告 TP/FP/FN、保留静态点和下游地图/定位影响，而不只报告“移除了多少点”。
- 不能证明：公开 benchmark 的标签、激光器和城市数据不等于当前室内/园区场景。

## M10 — lidar_localization_ros2 benchmark/recovery artifacts

- 来源：rsasaki0109 开源项目；[Benchmark/validation docs](https://github.com/rsasaki0109/lidar_localization_ros2/blob/main/docs/benchmarking.md)、[global localization docs](https://github.com/rsasaki0109/lidar_localization_ros2/blob/main/docs/global_localization.md)。状态：`inspected`。
- 核心内容：将 rosbag、候选位姿、匹配分数、运行时、reinitialization 和 Nav2 结果做成可追溯 artifact。
- 可借鉴：为重定位实验保留逐次 trial、候选、分数、延迟和最终动作结果。
- 不能证明：该项目的 success/validation 边界不是 DG-202611 官方判定。

## A. 平面与高程定位误差测试候选

### 1. 真值和坐标

- 优先级：测量型 RTK/全站仪/动作捕捉/高精度外部定位；若只能用 RTK 真值，必须报告其固定解状态、基站、天线杆臂和精度说明。
- 将经纬高转换为统一局部 ENU 坐标，并记录估计轨迹、真值轨迹、时间戳和外参。

### 2. 事件窗口

至少分开记录：

- 正常 BDS + 正常 LiDAR；
- BDS 短时中断 + LiDAR 正常；
- BDS 正常 + LiDAR 几何退化；
- BDS 中断 + LiDAR 几何退化并发；
- BDS 恢复和重新接纳。

### 3. 指标定义候选

对每个同步时刻：

- 平面误差：`e_xy = sqrt((e_E)^2 + (e_N)^2)`；
- 高程误差：`e_z = abs(e_U)`；
- 额外报告均值、RMSE、95 分位、最大值、超阈值比例和连续超阈值时长。

“优于 20 cm”到底是最大值、95 分位、均值还是其他统计量，必须向主办方确认；在确认前不能选择对自己有利的统计口径。

## B. 相邻帧有效特征重复率测试候选

候选公式：

`repeat_rate(t,t+1) = matched_valid_features(t,t+1) / valid_features(t)`

必须先冻结：

1. 有效特征是点、线段、角点、栅格占据单元还是描述子关键点；
2. 两帧是否先用轮速/IMU做运动补偿；
3. 只统计两帧共同可见的重叠区域，还是统计整帧；
4. 几何距离/角度/描述子相似度阈值；
5. 当分母为 0、观测被异常反射污染或帧丢失时如何处理；
6. 报告平均值、最低值、95 分位还是所有相邻帧都需满足 95%。

推荐先用 USIP 的“变换后最近邻距离小于 `ε`”作为概念起点，再改写为当前 2D LaserScan 可计算的定义；不能直接声称比赛指标已被文献定义。

## C. 主动重定位成功率测试候选

一次 trial 先定义为：在预设场景中触发失定位/退化 → 允许机器人按固定安全动作策略观测 → 算法输出候选/修正 → 在冻结时间窗内持续输出稳定位姿。

候选成功条件：

- 最终位置误差小于预先声明的阈值；
- 姿态误差和连续帧稳定性满足阈值；
- 不产生危险速度或越界运动；
- 恢复后能完成一个短导航/到点动作，作为任务级附加条件。

成功率候选：`success_rate = successful_trials / valid_trials`。

必须记录失败 trial，不得只保留成功样本；有效 trial 的排除条件、试验次数、场景随机化和置信区间需要在看到结果前冻结。95% 的官方阈值不自动决定 trial 数量，也不自动等于“19/20”。

## 当前建议

先向学长确认官方测试口径和是否提供真值设备；再用 1 个正常场景 + 1 个并发退化场景做小试验，先验证数据链、同步、指标脚本和失败记录能否工作。小试验通过前不做大规模实验，不把论文 benchmark 数字写成项目性能。
